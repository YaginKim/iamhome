- `방이름_가로x세로.png`: 지금 게임에 쓰는 방 그림 원본(사람·표지판 없음). 이 파일을 고쳐서 같은 크기로 주세요. 1칸 = 16×16픽셀.
- `방이름_guide.png`: 4배 확대 + 칸 선 + 표시
  - 파랑 = 사람이 서는 자리 (엄마, 사장님, 선생님 등)
  - 노랑 = 계산대 앞 (여기 서면 말을 걺)
  - 초록 = 물건 (키오스크, ATM, 카트, 코너, 번호표 기계, 자판기, 엘리베이터, 검색대)
  - 빨강 = 나가는 문
- 사람과 표지판(식품·생활용품·민원실 등)은 게임이 그림 위에 따로 그리니 방 그림에는 넣지 마세요.
- 걸을 수 있는 곳과 막힌 곳은 칸 지도로 정해져 있어요. 가구 위치를 바꾸면 알려 주세요. 칸 지도도 같이 맞춰요.
