# 기기 사이 저장: 구글 스프레드시트 연결하기

학생 기록을 선생님 구글 스프레드시트에 보관하면, 다른 태블릿이나 PC에서도 학년·반·번호만 고르면 이어서 할 수 있어요.
처음 한 번만 설정하면 되고 10분쯤 걸려요. 무료예요.

- 시트로 보내는 것: 학년-반-번호, 난이도, 끝낸 곳, 돈, 별, 스티커, 설정
- 보내지 않는 것: 꿈이든 카드의 이름과 주소 (각 기기에만 남아요. 새 기기에서는 기본 이름 '김꿈이'로 보여요)

## 1. 시트와 스크립트 만들기 (PC에서)

1. 구글에 로그인하고 주소창에 `sheets.new` 를 열어 새 스프레드시트를 만들어요. 이름은 `다녀오겠습니다 기록` 처럼 지어요.
   - 학교 구글 계정은 관리자가 막아 두어 7번이 안 될 수 있어요. 그러면 개인 구글 계정으로 하세요.
2. 위 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 왼쪽 `Code.gs` 에 있는 글을 모두 지우고, 이 파일의 내용을 모두 복사해서 붙여 넣어요.
   https://raw.githubusercontent.com/YaginKim/iamhome/main/tools/apps-script/Code.gs
4. 6번째 줄 `const SECRET = '여기에-비밀번호';` 의 따옴표 안을 선생님만 아는 비밀번호로 바꿔요. 영어·숫자 8자 이상을 추천해요.
   - 게임의 선생님 비밀번호(숫자 4자리)와는 다른 것이에요.
5. 디스크 모양 **저장** 버튼을 눌러요.

## 2. 웹 앱으로 배포하기

6. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
7. **유형 선택**(톱니바퀴) → **웹 앱** 을 고르고 아래처럼 정해요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
8. **배포** 를 누르면 권한을 물어요. **액세스 승인** → 내 계정 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**.
   - 선생님이 직접 만든 스크립트라서 나오는 안내예요. 이 스크립트는 이 시트만 읽고 써요.
9. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해요.

## 3. 게임에 연결하기

10. 게임 첫 화면 **선생님 → 기기 사이 저장** 에 웹 앱 주소와 4번의 비밀번호를 넣고 **연결하기** 를 눌러요.
    - 그 기기에 이미 있던 학생 기록도 시트로 올라가요.
11. 다른 기기: 같은 화면의 **링크 복사** 로 연결 링크를 복사해서 메신저나 메일로 보내고, 그 기기에서 열면 바로 연결돼요.
    링크에는 비밀번호가 들어 있으니 학생에게는 보여 주지 마세요.

## 알아 두기

- 같은 학생이 두 기기에서 동시에 하면 나중에 저장한 쪽 기록이 남아요.
- 인터넷이 끊겨도 게임은 그대로 되고, 기기에 먼저 저장했다가 인터넷이 다시 되면 시트로 보내요.
- 시트의 `기록` 탭에서 학생마다 마지막 저장 날짜, 난이도, 끝낸 곳 수를 볼 수 있어요. 마지막 칸(기록)은 고치지 마세요.
- 학생 기록을 지우려면 게임의 **선생님 → 학생 기록 → 학생 → 이 학생 기록 지우기** 를 쓰세요. 시트에서도 함께 지워져요.
- 스크립트를 고쳤다면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 바뀐 내용이 적용돼요. 주소는 그대로예요.
