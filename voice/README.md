# 대사 녹음

## 1. 게임 안에서 녹음하기 (추천)

게임 첫 화면 **선생님 → 대사 녹음하기**
- 대사를 하나씩 보여 줘요. **● 녹음** → 말하기 → **■ 멈추기** → **다음 ▶**
- 입력 장치(마이크)를 고를 수 있어요.
- 「말하는 사람」으로 거르면 엄마 역, 가게 사람 역처럼 나눠서 녹음할 수 있어요. 「녹음 안 한 대사만」을 켜면 남은 대사만 보여요.
- 이미 녹음된 대사를 다시 녹음하면 바로 바뀌지 않아요. 새 녹음과 원래 녹음을 들어 보고 **새 녹음으로 바꾸기** 또는 **원래 녹음 그대로 두기**를 골라요.
- 녹음은 그 기기에 저장돼요. 구글 시트(「기기 사이 저장」)가 연결돼 있으면 선생님 구글 드라이브의 「다녀오겠습니다 녹음」 폴더에도 올라가서, 연결된 다른 기기에서도 들려요.
- 녹음하지 않은 대사는 그대로 기계 음성(TTS)이 읽어요.

미리 준비할 대본: `docs/대사-녹음-대본.xlsx` (분류별 탭)

## 2. 파일로 넣기

1. 대본의 「녹음 파일 이름」대로 mp3를 만들어 이 폴더에 넣어요. 예: `v1a2b3c4d.mp3`
2. `voice/manifest.json` 목록에 파일 이름(확장자 빼고)을 추가해요. 예: `["v1a2b3c4d"]`

게임에서 녹음한 것이 있으면 그것이 먼저 나오고, 그다음 이 폴더의 파일, 그다음 TTS 순서예요.

## 대본 다시 만들기 (대사를 고쳤을 때)

```
python3 tools/voice_script.py
```
`docs/대사-녹음-대본.xlsx`, `.csv`, `data/voice-lines.json`(게임 안 녹음 목록)이 새로 만들어져요.
녹음 파일 이름은 대사 글자로 정해지므로, 고친 대사는 다시 녹음해야 해요.
금액이나 물건 목록처럼 매번 바뀌는 문장은 녹음할 수 없어서 TTS로 읽어요.
