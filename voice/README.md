# 대사 녹음

## 게임 안에서 녹음하기

게임 첫 화면 **선생님 → 대사 녹음하기**
- 대사를 하나씩 보여 줘요. **● 녹음** → 말하기 → **■ 멈추기** → **다음 ▶**
- 입력 장치(마이크)를 고를 수 있어요. 「말하는 사람」으로 역할별 대사만, 「녹음 안 한 대사만」으로 남은 대사만 볼 수 있어요.
- 이미 녹음된 대사를 다시 녹음하면 새 녹음과 원래 녹음을 들어 보고 **새 녹음으로 바꾸기 / 원래 녹음 그대로 두기**를 골라요.
- 녹음은 먼저 그 기기에만 저장돼요. 아래 **사이트에 올리기**를 해야 모든 기기에서 들려요.

## 사이트에 올리기 (모든 기기에서 들리게)

녹음 화면 아래 **사이트에 올리기**를 누르면 녹음 파일이 이 `voice` 폴더로 올라가요. 1~2분 뒤(사이트 배포가 끝나면) 사이트에 들어오는 모든 기기에서 녹음으로 들려요.

처음 한 번은 GitHub 열쇠(토큰)가 필요해요. 녹음하는 기기에만 넣어요.
1. https://github.com/settings/personal-access-tokens/new 를 열어요 (YaginKim 계정).
2. Token name: `다녀오겠습니다 녹음`, Expiration: 가장 길게
3. Repository access: **Only select repositories → iamhome**
4. Permissions → Repository permissions → **Contents: Read and write**
5. **Generate token** → `github_pat_`로 시작하는 열쇠를 복사해서 게임의 「GitHub 열쇠 넣기」에 붙여 넣어요.

열쇠가 어려우면 **녹음 파일 내보내기**로 받은 파일을 Claude에게 주세요. 대신 올려 드려요.

## 대본

미리 준비할 대본: `docs/대사-녹음-대본.xlsx` (분류별 탭). 대사를 고쳤으면 `python3 tools/voice_script.py`로 다시 만들어요.
녹음 파일 이름은 대사 글자로 정해지므로, 고친 대사는 다시 녹음해야 해요. 금액이나 물건 목록처럼 매번 바뀌는 문장은 녹음할 수 없어서 기계 음성(TTS)으로 읽어요.

들리는 순서: 그 기기에서 녹음한 것 → 이 폴더(사이트)의 녹음 → 기계 음성
